# Resources

### General Resources
- [repair.wiki](https://repair.wiki) - Repair knowledge repo.
- [iDevice Panic Log Analyzer](https://github.com/waynebonc/iDeviceLogAnalyzer-public) - A program designed to help parse through panic logs generated by Apple devices.
- [BadCaps](https://www.badcaps.net) - Tech repair forum, has a great repository for boardview files. (**EDIT:** DOWNLOADS ARE NOW FOR **PAID SUBSCRIPTIONS ONLY**. STILL A GOOD RESOURCE BUT THEY'RE SHITTY FOR THAT.) 
- [ForterFix BGA Tool](https://forterfix.com/gddr_pinout) - "BGA Interactive Schematic Visualization and Damage Check Tool" super cool online tool. Hard to explain but in short you can see the pinouts for a ton of common BGA ICs, like PS5 RAM, or GDDR6, etc. You can also select damaged pins and it will tell you if it will still work.
- [ConsoleFix](https://www.consolefix.shop/) - The storefront for Cod3rs pulled parts. Highly recommended.
- [IndiaFix](https://indiafix.in) - Massive free repository of boardviews, schematics, and software.
- [BiosHelp](https://bioshelp.com) - Copies of BIOS files for various devices.
- [FixMyApp](http://www.youtube.com/@fixmyappjim) - As much as I would like to link this persons resources directly, I can't find any one single repo. If you search their username + whatever you need you might be able to find some stuff. I've found detailed diagrams showing standby voltages for Xbox One, PS5, and etc.
- [Fritzchens Fritz](https://www.flickr.com/photos/130561288@N04/albums/) - Huge repo of high-res images of various things. Xray images of RDNA, etc, etc.

### PC Resources
- [macOS ISO Repo](https://archive.org/download/macos_iso) - Repo of macOS ISO files 13.0.1 and up.
- [TonyCSTech GPU Repo](https://drive.google.com/drive/folders/12XQpmc9tLwlRQjlo3Mn_XwKlVcV8XYGI?usp=drive_link) - Repository of GPU info including pinouts, schematics, and boardviews. 
- [TechPowerUp](https://www.techpowerup.com) - Review site but they include high-res images of GPU PCBs as well as listing off the IC models. Super useful for checking for missing components or figuring out ICs to replace/just identifying them.
- [LaptopTechInfo](https://laptechinfo.com) - Repository of various schematics and boardviews. I've only used it a handful of times so I won't 100% endorse it yet, but it has been solid the few times I've needed it.
- [DNS Speed Test](https://dnsspeedtest.online) - Test latency between various DNS services at once to find the best one for you.
- [DNS Check Tools](https://dnscheck.tools) - Performs a check on your DNS providers and reports DNSSEC results.

### Console Resources
- [retrosix.wiki](https://retrosix.wiki) - Repair knowledge repo, very detailed, typically includes a lot motherboard info.
- [Nintendo Support](https://en-americas-support.nintendo.com/app/pin) - Shortcut to the form for remotely removing parental controls on Nintendo Switches.
- [Console Service Tool](https://github.com/amoamare/Console-Service-Tool) - PlayStation UART reader and NOR flasher created by The Cod3r.
- [Nintendo Switch Modding Resources](https://damota.me/ssnc/) - Guides, serial checker, etc.
- [ForterFix UART Tool](https://forterfix.com/ps5_uart) - Online PS5 UART reader. 
- [ForterFix PCB Viewer](https://forterfix.com/switch_layers/) - PCB layers viewer for Switch 1 / 2 / Lite / OLED.
- [Pico Durango POST Code Reader](https://github.com/xboxoneresearch/PicoDurangoPOST) - Tools to read POST codes on Xbox's using a Raspberry Pi Pico. 
- [ZZAttack Switch Diode Readings](https://files.zzattack.org/index.php?dir=img%2Fconsole%2Fswitch%2Foled%2FComponents) - ZZAttack has some more resources if you go through it, but I wanted to highlight the set of diode readings they have hosted for the Switch.
